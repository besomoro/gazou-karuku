# 画像かるく（画像サイズ縮小 PWA）

端末内だけで画像を一括縮小する Android 向け PWA。画像は外部に送信されません。

## 機能
- 複数画像の一括縮小
- 縮小方法: おすすめ（長辺1920px・画質80%）／長辺px指定／画質指定／目標KB指定
- 出力形式: JPEG / WebP / PNG
- Exif（GPS・撮影日時など）は自動削除、向きは補正
- 共有ボタンで LINE などへ直接送信、個別保存、ZIP 一括保存
- オフライン動作（初回読み込み後）、ホーム画面に追加可能

## スマホへの入れ方
PWA は HTTPS 配信が必要です。例: GitHub Pages
1. このフォルダの `index.html, manifest.json, sw.js, icon-192.png, icon-512.png` をリポジトリに置き、Pages を有効化
2. Android の Chrome で URL を開く → メニュー「ホーム画面に追加」／「アプリをインストール」
3. 以降はオフラインでも起動できます

## 注意
- HEIC など Chrome が読めない形式は「読み込めない形式」と表示されます
